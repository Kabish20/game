# Game & Glory

A standalone game-discovery frontend built with React, Vite, and Tailwind CSS. It includes a responsive featured carousel, searchable and filterable catalog, favorites, local player profiles, and an original artwork set with fallbacks for every title.

## Run locally

```powershell
cd gaming-website
npm install
npm run dev
```

The Vite app runs at `http://localhost:5173/` and does not require a backend, database, or environment variables. Player accounts are stored only in the current browser. This local profile system is intended for the frontend demo and is not a substitute for production authentication.

## Quality checks

```powershell
cd gaming-website
npm run lint
npm run build
```
