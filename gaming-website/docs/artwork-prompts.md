# Artwork generation manifest

The production artwork was generated with the built-in image generation tool, then center-cropped and exported for the web at 85% JPEG quality.

## Shared card prompt

```text
Use case: stylized-concept
Asset type: portrait game-library card artwork
Primary request: original cinematic artwork of <direction below>
Style/medium: premium realistic video-game environment key art, painterly cinematic finish
Composition/framing: vertical poster composition, strong central depth, safe edges for a 4:5 card crop
Lighting/mood: immersive and non-graphic
Constraints: completely original characters and composition; no injury; no title; no text; no logos; no trademarked symbols; no watermark
Avoid: recognizable copyrighted character designs, weapons, fighting, UI elements, borders, typography
```
